RESEARCH QUESTION

How much additional non-stabilizerness can a shallow quantum circuit generate when its input is already entangled and non-stabilizer?

Source repository ↗Other projects ↗Interactive derivation ↗
Magic is a computational resource beyond stabilizer operations. The interesting optimization problem is not simply how many T gates a circuit uses: the initial state already contains magic, while the accessible entangling operations limit which transformations can realize a proposed optimum.
START HERE / AN EXPLANATION

From first principles to the research question.

A quantum computer is built from elementary operations called gates. Clifford gates are efficient to simulate classically; adding non-Clifford gates such as the T gate provides a resource known as magic. A CNOT gate entangles two qubits and its physical cost constrains which circuits we can implement.

MATHEMATICAL FOCUS / SCHEMATIC
01

The mathematical object

The analysis tracks the second stabilizer Rényi entropy M₂ via Pauli moments. By reducing Clifford+T constructions to Pauli-axis words, selected two-qubit instances can be enumerated symbolically rather than assessed only by floating-point optimization.

02

A concrete verified result

For a specified continuous family of partially entangled, magical two-qubit inputs and circuits with at most three T gates, the repository contains an exact algebraic certificate separating the unrestricted optimum from the optimum attainable with at most one CNOT. Its claimed gap is positive on the stated parameter interval. This is an exact result for the defined model and gate-counting conventions, not a general theorem for arbitrary states.

03

Why this is interesting

The project asks which aspects of input-state correlations determine whether a magic optimum is reachable within a restricted entangling budget. The current constructions suggest that correlations and gate placement can matter beyond a scalar input magic measure.
