RESEARCH / 04

Learning dynamics with memory.

Error-backflow-aware neural solvers for strongly non-Markovian open quantum systems.

∿
CURRENT STAGE: BENCHMARK AND REPRODUCTION
RESEARCH QUESTION

Can physical sensitivity of observables guide neural training toward the residual errors that matter over long memory times?

Source repository ↗Other projects ↗Interactive derivation ↗
In a non-Markovian quantum system the environment feeds information back into the subsystem. A neural approximation can look accurate locally while small residuals accumulate into large observable errors; this project tests whether adjoint sensitivities can improve training targets.
MATHEMATICAL FOCUS / SCHEMATIC
observable error ≈ ∫ adjoint sensitivity × residual dt
01

Methods

Start with a mathematically exact adjoint–residual identity, then compare neural collocation solvers against small-system exact dynamics and increasingly faithful interacting-fermion reference benchmarks.

02

Reproducibility

The repository includes a finite-bath interacting Anderson-impurity benchmark, a time-domain-decomposed PINN comparison, bath-coefficient reconstruction, and code for continuum-bath HEOM checks. This is a layered verification program, not yet proof of a better solver.

03

Negative results count

In the initial separate qubit benchmark the tested adjoint-weighting scheme made strong-memory global RMSE worse across the tested seeds. The result is documented rather than hidden; failure modes help determine the next objective.

04

Next experiment

Establish a converged HEOM reference, reproduce the published upstream baseline on matched observables and compute budgets, then test whether sensitivity weighting improves accuracy at equal computational cost.
